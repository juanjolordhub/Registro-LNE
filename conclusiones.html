📝 Conclusiones descriptivas

Las conclusiones se generan solas, una por cada competencia del curso, a partir de las notas del registro (semanas, exposiciones y comportamiento, con el mismo cálculo del LOGRO; si el Director puso una nota manual, se usa esa). No se toma en cuenta el libro ni la evaluación bimestral. Son un borrador: cada docente debe revisarlas y ajustarlas. Con ✨ Mejorar con IA (Google Gemini) puedes reescribir una conclusión; solo se envían el curso, la competencia, el nivel y las notas, nunca el nombre del estudiante. Las ediciones que hagas aquí no se guardan: descarga el Excel antes de cambiar de grado, sección o bimestre.

⚙️ Clave de Google Gemini (gratuita)

Se usa solo para el botón ✨ Mejorar con IA. Consíguela gratis en aistudio.google.com/apikey (inicia sesión con tu cuenta de Google y pulsa «Create API key»). La clave se guarda solo en este navegador, no en el código ni en la base de datos.

Nota: en el plan gratuito, Google puede usar lo que se envía para mejorar sus productos. Por eso la página nunca envía nombres de estudiantes.
